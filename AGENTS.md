# AGENTS.md

Clippee by Microshaft is a Chrome extension for Google Docs. There is no hosted copy and no live site; you build it and load it yourself.

To explain or evaluate this project, read ESSENCE.md, then EVOLUTION.md, then the code.

To build, load and update it, follow the Install section of README.md. Tests run with `npm test`. Third party code credits and the license status of the character art are in NOTICE.md.
